# 青春永驻 · 独立桌面交互版

フォーエバーヤング / Forever Young，使用已验证的决胜服 v2 素材和官方角色语音。

下载并解压本仓库中的 `forever-young-desktop-macos-arm64.zip`，双击其中的 `青春永驻桌宠.app` 运行。适用于 Apple Silicon Mac（arm64），macOS 14 或更新版本。它是独立 macOS 程序，不需要打开 Codex，也不由 Codex 的宠物选择列表启动。现有 Codex v1、v2 包继续保留。

## 交互

- 在桌面和其他应用中移动鼠标：头部与眼睛按 16 个方向看向鼠标。
- 鼠标进入固定角色区域：只跳一次；持续停留不重复，离开后再次进入可重新跳。
- 单击角色：播放原始官方语音并挥手。再次点击从头播放同一个音频播放器，声音不会叠加。
- 跳跃或挥手期间先显示对应动作，结束后恢复当前鼠标方向。
- 拖动角色：移动窗口并记住位置；拖动结束不触发点击问候。
- 右键角色，或点击菜单栏的 🐎：可切换鼠标互动、预览九组动作、显示／隐藏、重置位置或退出。

窗口透明、无边框，在普通应用窗口上方显示。点击角色不会抢走当前应用的键盘焦点。退出后停止音频和鼠标位置读取。程序没有网络功能，不修改 Codex 应用文件，不设置开机启动。

## 素材与画质

使用 v2 的 1536×2288 图集：原九组动作共 57 帧，新增视线 16 格，共 73 格。应用内部转换为 PNG 供 AppKit 读取，转换前后的 RGBA 像素一致。单帧原始素材仍为 192×208；窗口按 1.2 倍显示，这不增加原图细节。60 Hz 的窗口更新调度不代表 60 个独立绘制的动作帧。

语音是 Cygames 官方角色页的未剪辑音频，CV 海弓シュリ，约 2.9 秒。角色与官方素材归 Cygames，本应用为非官方个人同人制作，详见 `CREDITS.md`。
