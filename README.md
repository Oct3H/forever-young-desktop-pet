# フォーエバーヤング · macOS 桌宠 v3.8.0

[English](README.en.md)

Forever Young／青春永驻的非官方独立桌面应用，适用于 **Apple Silicon Mac、macOS 14+**。使用决胜服形象，提供鼠标互动、原角色录音、Codex／VS Code／PyCharm 本地联动及赛事工作台。它从 `.app` 启动，和 Codex 原生宠物素材包是两个产品。

## 下载与启动

1. [下载桌面版 ZIP](https://github.com/Oct3H/forever-young-desktop-pet/raw/refs/heads/main/forever-young-desktop-macos-arm64.zip)，解压整个文件夹。
2. 从旧桌宠右键菜单或菜单栏 🐎 退出旧版，再双击 `Forever Young.app`。可将完整应用复制到常用目录；无需重新编译。
3. 点击角色或右键打开工作台；菜单栏 🐎 可显示／隐藏、重置位置和退出。
4. 设置选择二次元／极简风格、中／日／英语言、主要联动来源及提醒选项。

各版本共用设置，同一时间运行一个。当前构建采用 ad-hoc 签名，尚未经过 Apple 公证；其他 Mac 首次启动可能要求确认来源。没有自动安装插件或修改系统权限、登录项、IDE 核心文件；无自建云端桥接服务。

## 主要功能

- 十六方向鼠标视线、每次悬停进入只跳一次、拖动左右跑、点击挥手和随机招呼；九组动作、73 格图集。
- 放大的五个图标：工作台、输入、运行、软件联动、收起；悬停可看功能名称。
- 17 段核验的原角色录音；点击／工作／完成／失败／中断场景控制、音量、试听、每日免打扰时段。录音不随界面语言变声。
- 三路状态同时接收；主来源决定角色状态，点击软件卡片选择操作对象。失败先于完成／中断，再到普通提醒，心跳去重。
- IDE 运行目标、工程、文件、工具预览；目标变化拒绝旧预览。保存或更换目标不会执行，运行／构建／测试分别记忆。
- 最多 200 条本地摘要历史、过滤、任务／控制台跳转、近似耗时与问题面板；不保存对话正文或控制台全文。
- 手动专注／会议、右侧收起、可暂停番茄钟与五分钟休息。
- JRA 国内平地 GⅠ与国际主要 GⅠ、日本马标记、实马 Forever Young 参赛计划及 JBIS 历史战绩；来源、确认状态和缓存时间可见，支持手动清理。
- 中文发走时刻为北京时间，日文为东京时间，英文为赛场当地时区；未知时刻不编造。可选开赛／出走变更提醒与 `.ics` 导出，提醒需要应用正在运行。

## 连接 Codex

同一 macOS 用户下打开并登录 Codex，桌宠默认读取 `~/.codex` 的本地任务，无需另绑账号或填写 API Key。自定义 `CODEX_HOME` 时从同环境启动。工作台 → Codex 任务选择跟随对象；设置 → 使用手册与连接检查兼容读取与官方通道。

文字输入锁定并核对任务。官方通道使用已安装 Codex CLI 的 App Server 启动空闲既有任务的下一轮，或继续／停止本通道启动的轮次；运行、测试、检查改动先填入可编辑草稿，确认发送才执行。审批遵守已有策略，需要时在本地窗口确认。

**不能接管另一个 Codex 客户端正在执行的轮次。** 已有 Desktop 任务仍可只读跟随；界面可能需要重新打开任务才能看到外部通道写入的新轮次。特殊授权／交互请求请回原客户端处理。官方通道属实验性接口，兼容读取依赖可能变化的本地格式；诊断不会猜测成功状态。桌宠桥接在本机，Codex 推理仍使用原有账号和服务。

## 连接 VS Code

1. 扩展页菜单 → **Install from VSIX…** → 安装 [3.8.0 插件](联动插件/forever-young-vscode-3.8.0.vsix)，重新加载窗口。
2. 打开自己的工程。插件遵守 Workspace Trust；受限模式不执行，不替你修改信任设置。
3. 默认使用“编译并运行当前文件”，适合 C++ 输入输出练习；无需逐题创建 tasks.json。VS Code 在前台时，角色下方 Run 图标也直接运行当前文件。
4. 当前本地文件先自动保存，使用已有编译器按 C17／C++17 编译；成功后在可输入的终端运行并获得键盘焦点，工作目录为源码所在目录。编译失败不会运行旧程序。
5. 软件联动 → VS Code → 展开“高级工程操作（可选）”，可运行项目、更换目标、构建、测试和打开问题面板。工程候选首次选择后记忆；当前文件入口绕过这些工程目标。
6. 当前文件也支持 Python、JavaScript，使用现有解释器／Node；复杂工程、参数和多文件程序使用高级操作。SSH 远程文件仍使用远程 IDE 的原运行入口。

支持运行项目、更换目标、当前文件、构建、测试、停止及问题／终端入口。Task 退出码决定成功／失败；Debug 结束无通用退出码，显示中断。任意终端命令不自动当作 Task 状态。最低 VS Code 1.90，本机验证版本为 1.140.0。

## 连接 PyCharm

1. IDE 插件页齿轮 → **Install Plugin from Disk…** → 安装 [3.8.0 插件](联动插件/forever-young-pycharm-3.8.0.zip)，重启 PyCharm。
2. 打开工程，配置已有本地 Python 解释器，并打开要运行的 `.py` 文件。
3. 软件联动 → PyCharm → “运行当前文件”：自动保存，使用临时 Python 配置；输入在 IDE 的 Run 控制台。无需为每道练习创建永久配置。
4. 多文件、参数、远程解释器或已保存目标，使用默认折叠的高级工程操作。

支持运行、更换目标、测试、停止及问题／Run 控制台入口。通过官方 ExecutionListener 接收开始与退出；零退出码为完成，非零为失败，常见停止码为中断。要求 PyCharm 2025.1+，本机验证 CE 2025.1.3.1；未覆盖所有 IDE 版本与其他 Mac。

插件版本为 **VS Code 3.8.0／PyCharm 3.8.0**；旧插件仍可提供基本状态；新的运行操作要求配套版本。IDE 与桌宠通过同用户目录中的原子 JSON 邮箱连接，没有公网监听；不需修改 IDE 核心文件。

## 配套更新与回退

应用及两个插件均为 **3.8.0**。升级时安装本目录的 VSIX 和 PyCharm ZIP，再分别重载 VS Code、重启 PyCharm。

设置 → 版本更新与回退可检查 GitHub 清单、导入完整解压目录、备份和切换本地版本。导入校验 SHA256 和应用签名；有活跃任务时禁止切换。插件需手动安装，应用不会静默修改 IDE。回退包位于 `回退版本/v3.7.2`，需同时安装其配套旧插件。详细步骤见 [v3.8 使用补充](v3.8使用补充.md)。
