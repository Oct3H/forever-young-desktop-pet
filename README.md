# フォーエバーヤング · 独立桌面交互版 v3.5

[English](README.en.md)

Forever Young / 青春永驻的非官方个人同人桌宠，适用于 Apple Silicon Mac、macOS 14+。v3.5 加入记忆运行目标、VS Code 单文件自动运行及按软件切换操作栏；保留本地 Codex 发送、三路状态队列、两种风格、三种语言与离线说明书。角色素材未变，见 [CREDITS.md](CREDITS.md)。

## 安装与启动

1. 解压 forever-young-desktop-macos-arm64.zip。
2. 用角色右键／菜单栏 🐎 退出旧桌面版，再双击青春永驻桌宠.app；可以复制应用到常用文件夹。
3. 同一 macOS 用户下打开已登录的 Codex。桌宠自动读取本机任务，无需新账号绑定或 API Key。
4. VS Code / PyCharm 需安装下述本地插件，并打开项目。

各桌面版共用应用标识，以继承位置、尺寸和界面设置；同一时间只运行一个。v3.4.1 成品完整保留。本应用独立运行，不从 Codex 原生宠物列表开启，也没有替换原生宠物渲染器。没有修改系统权限、设置、登录项或启用常驻云端服务器。

## 点击气泡与工作台

点击角色仍播放原有官方问候并挥手。下方显示五个图标：工作台、文字输入、运行、软件联动、关闭；悬停显示功能名称，支持辅助功能标签。颜色随二次元／极简设置切换。靠近屏幕边缘会调整位置，15 秒后隐藏；拖动不会误触点击。

每次点击显示主要联动来源的最新状态，并随机附一条文字问候；新状态首次提醒优先，问候不覆盖提醒。随机问候没有新增或合成角色语音。连续点击当前正在展示的状态提醒时，保留该提醒。

右键／菜单栏 🐎 → 打开工作台。右上角设置选择界面、语言和主要联动来源。功能栏按内容宽度排列，全部功能菜单提供 Codex、国内／国际 GⅠ、Forever Young、软件联动入口。窗口最小宽度 320 像素，支持两种界面 × 三种语言，长文换行与列表滚动；设置保存在本机。

## v3.5 软件操作与说明书

主导航新增“软件联动”，与 Codex、国内／国际 GⅠ并列；Forever Young 等模块仍可从“全部功能”进入。主要联动来源摘要只读；点击软件卡片可切换下方操作栏，通知优先来源仍在设置中选择。连接教程、官方通道检查及状态动作开关集中在设置 → 使用手册与连接，包含“桌宠使用 / Codex / VS Code / PyCharm”四部分，随界面语言切换，离线可读。

VS Code“运行项目”会获取已有／自动检测的任务或调试配置，多个候选只需在工作区首次选一次；后续复用。“更换运行目标”只保存选择。“运行当前文件”可直接运行 Python、JavaScript、C／C++ 单文件，使用现有工具与项目解释器，无需生成 tasks.json。C17／C++17 编译失败不会运行旧程序。多文件、库、特殊选项与测试仍需项目本身的配置，运行／构建／测试分别记忆目标。

下载和启动不会自动安装插件、生成项目配置或修改 IDE 程序文件。其他人安装成品内 3.5.0 插件并打开自己的项目即可连接；已用旧插件的用户需更新。本机已升级用户目录插件，核心应用未修改。桌宠与 IDE 使用同一用户；配置记忆由 IDE 的工作区／项目存储管理。

当前 app 为 ad-hoc 签名、未公证，其他 Mac 首次打开可能需要用户确认来源；不能保证所有软件版本兼容。本轮只评估自动配置：检测已有任务、提供经过确认的配置草稿可行，但不自动创建／覆盖配置。项目入口、解释器、参数和环境不能对所有项目可靠推断，推荐向导让用户确认。

## 三路联动与提醒排序

状态优先来源只在设置中选择：自动、Codex、VS Code、PyCharm。软件联动页显示配置模式与当前主来源；点击软件卡片切换下方操作栏。

- 自动：已连接的前台软件优先；前台不是这三个软件时，选择最近发生状态变化的活跃来源，再回退至已连接的 Codex 或最近连接的 IDE。
- 固定：宠物状态动作和点击显示以该来源为主；若它未连接，会显示未连接，不暗中换成其他来源。
- 三路始终同时接收，软件联动页分别显示状态、项目、任务与运行数量。选择主来源不会停掉其他来源。
- 待展示提醒按失败 → 完成／中断 → 普通状态排序；同级优先主要来源，再按到达顺序。正在展示的状态提醒保留约六秒。相同事件或心跳不会重复提醒，启动不重播历史完成事件，过期提醒会丢弃。
- IDE 每十秒发送心跳，约 35 秒没有心跳即失效。多个 IDE 窗口／项目分别发送；同一软件优先显示仍有运行任务的实例。
- 联动状态动作开关同时控制三路状态驱动；状态卡片仍可查看。拖动、悬停单次跳跃、点击挥手／语音等互动结束后恢复联动动作。

## Codex 文字直达与官方事件

打开文字输入时锁定当前跟随任务，显示任务标题及项目路径。发送前再次检查任务是否有效，按该任务的 threadId 提交，避免自动跟随切换造成误发。运行项目／测试／检查改动快捷键只填入可编辑提示词，点击发送才执行。复制并打开 Codex 作为兼容备用入口保留。

直接发送使用已安装官方 CLI 的 App Server：initialize → thread/resume → turn/start；本通道已启动的活跃轮次使用 turn/steer 和 expectedTurnId，停止使用 turn/interrupt。不指定新的模型、沙盒或审批策略，沿用任务设置。官方生命周期事件驱动工作、等待工具、检查、完成、失败和中断动作，不保存对话正文、工具输出或 CLI 错误日志。

**当前机器的重要限制：Codex Desktop 没有开放共享官方控制 socket。** 桌宠使用私有 stdio 通道向空闲的既有任务启动下一轮；可以继续输入或停止本通道启动的轮次。另一个 Codex 客户端正在执行的轮次不可接管，发送会明确说明原因。已在 Codex Desktop 执行的任务仍通过只读兼容适配器接收状态。因此，不能把本版说成能够实时操控所有 Desktop 活跃轮次的完整替代客户端。桌面界面可能需要重新打开任务才能载入外部通道的新轮次。

若本机已有官方 app-server-control 控制 socket，优先使用 CLI proxy；不会主动启动共享 daemon，不使用内部 IPC 或键盘模拟。官方接口仍属实验性协议，升级后可能需要适配。

本通道执行时，命令／文件审批显示本地确认窗口，默认不自动许可。其他交互请求（例如特殊工具授权或输入请求）暂不支持，会明确拒绝；需要完整交互时请在 Codex 使用原客户端。原客户端发起的任务仍在原客户端审批。设置 → 使用手册与连接 → Codex 显示兼容读取状态和官方通道状态，并提供分别检查的按钮；官方通道连接成功不等于能接管其他客户端。

兼容适配器每秒以 SQLite 只读连接读取本机任务元数据并增量解析所选 JSONL 的生命周期字段，不直接写数据库、配置或审批记录，也不读取凭证。默认目录 ~/.codex；自定义 CODEX_HOME 可从同环境终端启动。本机验证 CLI 0.160.0；内部记录格式变化会提示错误并停止猜测状态。桌宠自己不需要云端桥接服务；正常 Codex 推理仍按已有账户和服务运行。

## VS Code 本地插件

成品包含联动插件/forever-young-vscode-3.5.0.vsix，源码位于联动插件/VSCode。

1. VS Code 扩展页菜单 → Install from VSIX… → 选择该文件，然后重新加载窗口。
2. 打开自己的项目。插件遵守 VS Code Workspace Trust；受限模式下不运行。仅信任你确认安全的工程。
3. “运行项目”使用已有／自动检测的 Task 或 Debug 配置，首次有多个目标时选一次，后续自动复用；“更换运行目标”只保存选择。“运行当前文件”直接使用现有工具执行单文件，无需生成配置。构建／测试按 TaskGroup 筛选；停止选择具体任务。

插件使用官方 task/debug 事件：任务开始为工作中，退出码 0 为完成，非零为失败，未确认退出码为中断。Debug API 不提供通用退出码，因此 Debug 结束标为停止／中断，不伪称测试成功。已有运行任务也会被识别。普通终端随意输入的命令没有 VS Code task 事件，不会被自动当作运行状态。

最低 VS Code 1.90；本机 1.138.0 已验证实际任务开始、成功、失败及桌宠命令选择配置。

## PyCharm 本地插件

成品包含联动插件/forever-young-pycharm-3.5.0.zip，源码位于联动插件/PyCharm。

1. PyCharm 的 IDE 插件页齿轮 → Install Plugin from Disk… → 选择 ZIP，重启 IDE。这里只设置 IDE 插件，不涉及 macOS 系统设置。
2. 打开项目并使用已有解释器和保存的 Run/Debug Configuration。
3. “运行项目”复用记住的目标；首次使用 IDE 当前配置或唯一候选，无法确定时在标准弹出列表选一次。“更换运行目标”只保存选择；测试单独记忆测试配置，停止确认当前项目进程。

插件通过官方 ExecutionListener 接收进程开始与结束，退出码 0 为完成，非零为失败，常见停止码 130/143 为中断；不保存控制台输出。不能监视 IDE 外部的任意 Python 程序。本版要求 PyCharm 2025.1+；在本机 Community 2025.1.3.1 已验证插件加载、配置选择、真实 Python 运行成功与失败。

## 本地桥接接口

统一命令入口 PetCommand、IntegrationHub 状态队列、OfficialCodex / LocalCodexConnection / IDEBridge 适配器与赛事信息提供者分离。IDE 使用用户目录中的原子 JSON 邮箱：~/Library/Application Support/ForeverYoungPet/Bridge/，子目录 events / commands / acks。它不是 TCP 服务，也不监听公网。

事件版本 1，字段为 source、instance（每个窗口／项目 UUID）、sequence、sentAt（Unix 毫秒）、state、runID、title、project、activeCount。仅接收 vscode / pycharm；固定状态为 idle / working / waiting / review / completed / failed / interrupted / disconnected。事件有大小、字段、时效和序号校验，不含提示词或控制台正文。

IDE 接受已实现的固定指令 run / chooseRun / test / stop；VS Code 另有 build / runFile。命令锁定画面显示的来源与实例，十五秒过期。ProcessExecution 将程序与参数分别传递，不拼接任意 shell 字符串。ack 仅表示交付／操作返回，任务结果以生命周期事件为准。邮箱按当前用户设置权限；旧固定状态通知接口保留，不执行命令。
